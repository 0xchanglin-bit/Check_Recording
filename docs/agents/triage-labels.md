# Triage 標籤

技能都用五個標準 triage 角色來溝通。這份檔案把這些角色，對應到這個 repo 的 issue tracker 實際在用的標籤字串。

| 技能裡的角色（Wu 的技能）| 我們 tracker 裡的標籤 | 意思                        |
| ------------------------ | --------------------- | --------------------------- |
| `needs-triage`           | `needs-triage`        | 維護者要評估這個 issue      |
| `needs-info`             | `needs-info`          | 在等回報者補資料            |
| `ready-for-agent`        | `ready-for-agent`     | 已經規格化完整，可交給 AFK agent |
| `ready-for-human`        | `ready-for-human`     | 要人工實作                  |
| `wontfix`                | `wontfix`             | 不會處理                    |

當某支技能提到某個角色時（例如「貼上 `ready-for-agent` 這個 triage 標籤」），就用這張表裡對應的標籤字串。

右邊那一欄，改成你實際在用的字。
